# Week 3 — Prototipi UI/UX

## What I did

- Built the mobile-first Albanian citizen PWA shell.
- Added fixed bottom navigation with a central camera action.
- Added home feed, map preview, reports, profile, report sheet and status cards.
- Added dark-compatible design tokens, safe mobile spacing, manifest and service worker.
- Added a responsive municipality dashboard at `/admin`.

## How to demonstrate

Open `/` on a phone-sized browser and tap each bottom navigation item. Open `/admin` for the desktop municipality view.
